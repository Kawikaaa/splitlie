# Landing Page /welcome

Mode: Persuade. Only the public landing surface is in scope. Login, signup, dashboard, routes, business logic and user data remain untouched.

## Direction contract

THESIS: Make personal and shared money understandable through a punctation-free oversized statement and an illustrative ledger, not floating panels and decorative gradients.

OWN-WORLD: User-pinned Swiss typography, true white #ffffff, charcoal #151915, lime #b8f26a, self-hosted Geist, 8px spacing grammar, flat surfaces, fine gray rules, compact 6–10px corners.

STORY: A new user understands personal tracking first, shared spaces when needed, traceable balances, and can create an account or log in.

FIRST VIEWPORT: Left two-thirds bold unpunctuated heading, supporting real copy and lime registration CTA. Right third a charcoal/white illustrative financial ledger. A ruled capabilities rail leads into open editorial feature rows.

FORM: Explicitly user-pinned Swiss Style with white, black and lime. No new capabilities, claims, charts, or testimonials. This precise brief overrides a concept tournament. Hero and continuation Image Gen references drive composition; existing translated product copy wins differences in generated wording.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Implementation deviations

- No generated raster ships as UI: all content, controls, preview and icons remain semantic React/CSS and the existing Phosphor icon family.
- CTA retains real translation “Create your account”, caption retains “Illustrative preview”, rather than generated shorter alternatives.
- Chinese title breaks after “让日常财务” to preserve a natural phrase. Other locales wrap responsively.
- Existing coffee sample uses the existing utensils icon; no new icon dependency or imagery.
- Only English/Chinese public language controls remain, as before. Existing settings language functionality is untouched.
